# 🤖 Simple AI Chatbot

A lightweight AI-powered chatbot built using **HTML, CSS, and JavaScript** that interacts with the OpenAI API to generate responses in real time.

## ✨ Features

* Interactive chatbot UI
* Show/Hide chatbot window
* Send messages using button click or Enter key
* Real-time AI responses using OpenAI API
* Auto-scroll chat messages
* Responsive and user-friendly design

## 📂 Project Structure

```bash
project-folder/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How It Works

1. User clicks the chatbot icon to open the chat window.
2. User enters a message.
3. Message is sent to the OpenAI API.
4. AI generates a response.
5. Response is displayed in the chat interface.

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* OpenAI API

## ⚙️ Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/simple-ai-chatbot.git
cd simple-ai-chatbot
```

### 2. Add Your OpenAI API Key

Open `script.js` and replace:

```javascript
const apiKey = "your-api-key";
```

with:

```javascript
const apiKey = "YOUR_OPENAI_API_KEY";
```

### 3. Run the Project

Simply open `index.html` in your browser.

Or use VS Code Live Server:

```bash
Right Click index.html → Open with Live Server
```

## 🔒 Security Note

⚠️ Do not expose your API key in client-side code for production applications.

For production:

* Use a backend server
* Store API keys in environment variables
* Make API requests from the server
